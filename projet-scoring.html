Analyse de données bancaires, modélisation prédictive et stratégie de rétention actionnable.

PythonScikit-LearnPandasBusiness Intelligence

Le challenge

Dans un contexte bancaire concurrentiel, acquérir un client coûte plus cher que le retenir. L'objectif était de construire un outil capable d'anticiper quels clients risquent de quitter la banque.

Au-delà de la prédiction binaire (partira / ne partira pas), l'enjeu était de fournir au service marketing un score de fidélité actionnable pour prioriser les relances.

85%Précision globale
83,4%AUC
~45 ansÂge critique identifié

Approche & profiling

J'ai utilisé une approche statistique rigoureuse (tests ANOVA et Chi-deux) pour sélectionner les variables pertinentes. Le modèle final — un arbre de décision optimisé — a permis d'isoler le profil type du client fragile :

  • Âge : 40–50 ans
  • Solde moyen : ~45 700 €
  • Comportement : inactif, produit unique

La solution : le « score de risque »

Plutôt que de livrer un code brut, j'ai transformé les probabilités du modèle en une segmentation métier claire pour les conseillers :

🔴 Urgent — top risque Score < 750 Action : appel immédiat / offre de rétention
🟡 À surveiller Score 750 – 900 Action : nurturing par email
🟢 Sans problème Score > 900 Action : cross-selling

Compétence mise en avant — relier la statistique inférentielle, le machine learning et la valeur métier : un modèle n'a de sens que s'il se traduit en une décision opérationnelle pour l'utilisateur final.
